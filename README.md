# Event Registration System

## About The Project
This project is an educational console application designed to manage participant registrations for community events, tech meetups, and workshops. I developed this system to practice fundamental software engineering concepts, specifically focusing on data management, user input handling, and logical workflow design.

## Key Features & Technical Concepts
* **Data Management:** Storing and retrieving attendee information efficiently.
* **Input Validation:** Ensuring accurate data entry and handling potential user errors.
* **Control Structures:** Utilizing loops and conditional statements for dynamic menu navigation.

## Learning Outcomes
Building this system provided hands-on experience in modeling real-world administrative tasks into software solutions. It reinforced my understanding of maintaining data consistency and writing modular, clean code.
